# lab5Popovych - Bracket validator
lab5Popovych helps you validate balanced brackets in strings, such as '()' '<>' '[]' '{}'
## Instalation
```bash
pip install lab5popovych
```

Usage
use the validateString(String s) function and throw ValidationError
>validateString("()")
>
>True

>validateString("(")
> 
> lab5Popovych.main.ValidationError: is not a valid expression: (at 0)
